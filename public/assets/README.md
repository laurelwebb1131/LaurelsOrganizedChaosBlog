# Laurel's Organized Chaos visual asset pack

The approved asset pack for the final homepage is stored persistently in the project's ChatGPT Library as:

`/Laurels Organized Chaos/Laurels_Organized_Chaos_Asset_Pack.zip`

The pack contains the eight approved generated source sheets plus 61 optimized individual WebP crops.

## Runtime destination

When the binary assets are placed in the repository, they belong in:

`public/assets/loc/`

The homepage already has graceful CSS/markup fallbacks. Missing art files therefore must never break navigation, CMS content, or page layout.

## Critical rules

- Do not replace CMS text with text baked into generated artwork.
- Decorative generated art is `aria-hidden` or has empty alt text.
- Real post images, real About imagery, categories, and copy continue to come from the CMS.
- Keep source sheet imagery out of semantic content.
- Optimize large art before production.
- Preserve the dark pink/purple/blue/black palette and ornate gothic scrapbook treatment.
